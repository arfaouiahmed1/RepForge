## 2026-08-22 Task 6 backend JVM build fix (worker)
- Kotlin block comments NEST: a literal /* inside KDoc (e.g. '/v1/*' in Application.kt route docs) opens a nested comment and the closing */ only unwraps one level, so half the file silently becomes comment -> 'Unclosed comment' at EOF plus cascading 'Unresolved reference' errors in other files. Never write /* inside block comments; use /v1/ or backticks.
- Kotlin 2.4 + Gradle 9.5: kotlinOptions DSL is a script ERROR (use top-level kotlin { compilerOptions { jvmTarget.set(JvmTarget.JVM_17) } }); io.ktor.plugin 3.1.1 is UNUSABLE on Gradle 9 (its bundled shadow maps the removed mainClassName property -> ':startShadowScripts' fails at configuration) - drop it, apply plain pplication, keep explicit versioned ktor-* deps; Android Studio JBR may be JDK 25 so also pin tasks.withType<JavaCompile> { options.release.set(17) } or Java/Kotlin target validation fails (25 vs 17).
- Ktor 3.1.1 bearer auth DSL lives directly in io.ktor.server.auth (BearerAuthKt); there is NO io.ktor.server.auth.bearer package on the classpath - import io.ktor.server.auth.bearer.* fails with Unresolved reference 'bearer'. Verify package layout against the actual jar (gradle cache) instead of trusting old blog snippets.
